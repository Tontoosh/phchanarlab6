# Лаборатори №6

Оюутны нэр: **Б.Дөлгөөн**  
Оюутны код: **B242270136**

## A1. Сонголт ба төлөөлөх утгууд

Тестийн суурь орчин: A данс идэвхтэй, B данс идэвхтэй бөгөөд A-аас өөр, F данс царцаагдсан, X ID-тай данс байхгүй. A ба F дансны валют MNT, үлдэгдэл 100,000 MNT, өдрийн лимит 200,000 MNT, өнөөдрийн ашигласан лимит 50,000 MNT тул үлдсэн лимит 150,000 MNT байна. Туршилтын тогтмол ханш нь 1 USD = 2,000 MNT; шимтгэлгүй гэж таамаглав. Энэ нь тестийн өгөгдөл юм.

| Параметр | Сонголт / property                                     | Төлөөлөх утга                            | Тэмдэглэгээ                                    | Үндэслэл                                                                             |
| -------- | ------------------------------------------------------ | ---------------------------------------- | ---------------------------------------------- | ------------------------------------------------------------------------------------ |
| from     | Valid / fromExists, fromActive                         | A                                        | property                                       | Данс байгаа бөгөөд царцаагдаагүй.                                                    |
| from     | Frozen / fromExists                                    | F                                        | [ERROR]                                        | Царцаагдсан данснаас шилжүүлэхэд ERROR_FROZEN буцна.                                 |
| from     | Missing                                                | X                                        | [ERROR]                                        | Байхгүй эх данс ERROR_NO_FROM үүсгэнэ.                                               |
| to       | Valid / toExists, distinct                             | B                                        | [IF fromExists]                                | Хүлээн авагч эх данснаас өөр бөгөөд оршин байна.                                     |
| to       | Missing                                                | X                                        | [ERROR]                                        | Байхгүй хүлээн авагч ERROR_NO_TO үүсгэнэ.                                            |
| to       | SameAsFrom                                             | from-ийн ID                              | [ERROR], [IF fromExists]                       | Оршин байгаа нэг данс руу өөрөөс нь шилжүүлэхэд ERROR_SAME_ACCOUNT буцна.            |
| amount   | BadAmount                                              | 0; нэмэлт төлөөлөгч −1                   | [ERROR]                                        | amount ≤ 0 үед ERROR_BAD_AMOUNT буцна; үндсэн тооцоонд энэ нь нэг сонголт.           |
| amount   | Normal / amountPositive, withinBalance, withinLimit    | 10,000 MNT эсвэл 5 USD                   | [IF fromActive AND toExists AND distinct]      | Хөрвүүлсэн 10,000 MNT нь үлдэгдэл болон үлдсэн лимитэд багтана.                      |
| amount   | AtBalance / amountPositive, withinBalance, withinLimit | 100,000 MNT                              | [SINGLE], [IF remainingLimit ≥ balance]        | Үлдэгдэлтэй яг тэнцүү дүн зөвшөөрөгдөх хил заагийг нэг тусгай тестээр шалгана.       |
| amount   | OverBalance                                            | 100,001 MNT                              | [ERROR], [IF remainingLimit ≥ convertedAmount] | Дүн үлдэгдлээс хэтэрсэн боловч лимитэд багтах тул зөвхөн ERROR_INSUFFICIENT үүсгэнэ. |
| amount   | OverLimit                                              | 150,001 MNT; setup: үлдэгдэл 300,000 MNT | [ERROR], [IF balance ≥ convertedAmount]        | Үлдэгдэл хүрэлцэх ч үлдсэн лимитээс хэтэрсэн тул зөвхөн ERROR_LIMIT үүсгэнэ.         |
| currency | Same                                                   | MNT                                      | property                                       | Дансны валюттай ижил тул хөрвүүлэлт шаардлагагүй.                                    |
| currency | Different                                              | USD                                      | [IF exchangeRateAvailable]                     | Дүнг тогтмол ханшаар MNT-д хөрвүүлж байж үлдэгдэл, лимиттэй харьцуулна.              |

`convertedAmount` нь хүсэлтийн amount-ийг эх дансны валют руу хөрвүүлсэн дүн. Normal-ийн төлөөлөх утга currency сонголтоос хамаарна. AtBalance-ийг SINGLE болгон MNT-аар нэг удаа шалгана; USD хувилбарын боломжит төлөөлөгч 50 USD боловч үндсэн багцад оруулахгүй.

### Далд орчны сонголтууд

| Орчны хүчин зүйл                | Сонголт ба төлөөлөх утга                                            | Ашиглалт / хязгаарлалт                                                                                             |
| ------------------------------- | ------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| Эх дансны үлдэгдэл              | Суурь: 100,000 MNT; лимитийг тусгаарлах: 300,000 MNT                | OverLimit үед 300,000 MNT болгож үлдэгдлийн алдааг арилгана.                                                       |
| Өдрийн ашигласан лимит          | Суурь: 50,000 / 200,000 MNT; бүрэн ашигласан: 200,000 / 200,000 MNT | Үлдсэн лимит = өдрийн лимит − ашигласан дүн; бүрэн ашигласан хувилбар нь нэмэлт лимитийн тестийн setup байж болно. |
| Ханш                            | MNT→MNT: 1; USD→MNT: 2,000                                          | Different валютын тестэд хөрвүүлэлтийн үр дүнгээр шалгана.                                                         |
| Дансны төлөв ба оршин байх эсэх | A, B идэвхтэй; F царцаагдсан; X байхгүй                             | from, to сонголтын төлөөлөгчдийг тодорхойлно.                                                                      |

Эдгээр нь үндсэн дөрвөн параметрийн сонголтыг бодит болгох setup юм. Үндсэн N → M тооцоонд бие даасан үржүүлэгч болгохгүй; жишээлбэл OverLimit-ийн үлдэгдэл нь тухайн сонголтоор тодорхойлогдоно. Тодорхойлолтод ханш олдохгүй, үл мэдэгдэх валют зэрэг алдааны үр дүн байхгүй тул тэдгээрт шинэ ERROR зохиогоогүй.

## A2. Хязгаарлалт ба тохиолдлын тоо

### Олон алдааны давуу эрэмбэ

**ERROR_NO_FROM → ERROR_FROZEN → ERROR_NO_TO → ERROR_SAME_ACCOUNT → ERROR_BAD_AMOUNT → ERROR_INSUFFICIENT → ERROR_LIMIT.**

Тодорхойлолт олон алдааны эрэмбийг заагаагүй тул эхлээд эх дансны боломж, дараа нь хүлээн авагч, эцэст нь дүнгийн нөхцөлийг шалгах дарааллыг тестийн oracle-ийн таамаглал болгон сонгов; хэрэгжүүлэлт өөр дараалалтай бол шаардлагыг тодруулна.

### Үндсэн багцын дүрмүүд

1. **[ERROR]:** Frozen, Missing-from, Missing-to, SameAsFrom, BadAmount, OverBalance, OverLimit гэсэн долоон алдааны сонголтыг тус бүр нэг тусгаарласан тохиолдлоор шалгана. Бусад параметрийг хүчинтэй суурь утгад тогтоосноор эхний алдаа өөр алдааг нуухгүй.
2. **Алдааны суурь утгууд:** from=Valid, to=Valid, amount=Normal, currency=Same; тухайн шалгаж буй алдааны сонголтоор зөвхөн холбогдох параметрийг солино. SameAsFrom үед to=A байна. OverLimit үед үлдэгдлийг 300,000 MNT болгон өөрчилнө.
3. **[SINGLE]:** AtBalance-ийг from=Valid, to=Valid, currency=Same орчинд нэг удаа шалгана. Энэ нь хил заагийн тусгай тестийг бусад сонголттой үржүүлэхгүй гэсэн тест сонголтын шийдвэр юм.
4. **[IF/property]:** Normal, AtBalance болон дүнгийн тусгаарласан алдааг шалгахын тулд эх данс идэвхтэй, хүлээн авагч байгаа бөгөөд өөр байна. SameAsFrom нь эх данс оршин байгаа үед утгатай.
5. **[IF/property]:** OverBalance үед convertedAmount ≤ remainingLimit; OverLimit үед convertedAmount ≤ balance байна. Эдгээр setup нь үлдэгдэл ба лимитийн алдааг тус тусад нь шалгах боломж өгнө.
6. **Валютын хамралт:** Normal амжилттай шилжүүлгийг Same болон Different валютаар хоёулангаар шалгана. Үндсэн багцын ERROR болон SINGLE тестүүдийг Same валютаар тогтооно; алдаа × хөрвүүлэлтийн хослолууд энэ багцад хамрагдахгүй.

### N → M тооцоо

Хязгаарлалтгүй нэрлэсэн сонголтын бүрэн олонлог:

```text
From:     3  (Valid, Frozen, Missing)
To:       3  (Valid, Missing, SameAsFrom)
Amount:   5  (BadAmount, Normal, AtBalance, OverBalance, OverLimit)
Currency: 2  (Same, Different)

N = 3 × 3 × 5 × 2 = 90
```

Энэ нь сонголтын Cartesian үржвэр бөгөөд бүх 90 хослол утгын хувьд боломжтой гэсэн үг биш. BadAmount-ийн 0 ба −1 нь нэг ангийн төлөөлөгч тул тусдаа үржүүлэгч биш.

ERROR болон SINGLE дүрмээр үндсэн багцыг багасгавал:

```text
Тусгаарласан ERROR: 2 (from) + 2 (to) + 3 (amount) = 7
Normal амжилттай:   1 × 1 × 1 × 2 валют          = 2
AtBalance SINGLE:                               = 1

M = 7 + 2 + 1 = 10
N → M: 90 → 10
```

M=10 нь дээр тодорхойлсон category-partition сонголтын дүрмээр үүсэх үндсэн тестийн хүрээний тоо, PICT-ийн pairwise гаралтын мөрийн тоо биш. A3-т шаардлагатай давхар алдааны тохиолдлыг энэ тусгаарласан багцад нэмэлтээр оруулна; нэг ийм мөр нэмбэл A3 хүснэгт нийт 11 мөртэй болно. Давхар алдааны нэмэлт мөр нь үндсэн [ERROR] тусгаарлах дүрмийн гаднах зориудын тест юм.
